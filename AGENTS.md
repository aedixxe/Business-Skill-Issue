# Business Skill Issue

This repository distributes the `business-skill-issue` skill and its local project timeline renderer.

## Scope

- Keep the first version small: one adaptable workflow, optional stages with reasons, versioned evidence, and a local HTML timeline.
- Skill instructions live in `skills/business-skill-issue/`. Repository documentation and release tooling live outside the installable skill where appropriate.
- Use synthetic examples only. Never commit customer materials, project workspaces, credentials, private links, or machine-specific paths.
- Generated project timelines are local by default. Publishing this skill does not authorize publishing a user's project data.
- Keep instructions, the pipeline data contract, renderer, and examples consistent. Run relevant validation before releasing.
- Preserve concurrent edits. Assign ownership when delegating work on shared files.

## User experience

- The display name is **Business Skill Issue**; the skill identifier is `business-skill-issue`.
- A capabilities question should receive a helpful description of supported work and ways to start, without creating project files.
- Keep document preparation, sending, approval of a specific version, and readiness for implementation distinct.
- Stage progress must reflect evidence, including partial answers, technical blockers, and changes after approval.
